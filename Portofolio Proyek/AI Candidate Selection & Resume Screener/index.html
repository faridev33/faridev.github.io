Frontend Architecture

  • Framework: React 19 + Vite (dikonversi ke Standalone Native Vanilla)
  • Styling: Modern Tailwind Inspired CSS dengan variable token modular
  • State Management: Real-time session switching & local state caching
  • Interactivity: Dynamic weight recalculation, interactive chatbot, drag-drop

Backend Architecture

  • Framework: Django 5 + Django REST Framework (DRF)
  • Document Parser: PyMuPDF4LLM + fitz fallback untuk scan visual
  • JSON Resilience: json-repair & safe regex parse untuk menjamin validitas output LLM
  • File Storage: Partitioned session storage (`media/sessions/session_/`)

AI & Prompt Engineering

  • Primary LLM: Qwen 3.8 Max via OpenRouter (1,000,000 tokens context)
  • In-Memory Evaluation: Membandingkan seluruh kandidat dalam 1 single prompt besar
  • Evaluation Rigor: Konsistensi simbol ✔️, ⚠️, ❌ terhadap final fit score
  • Deterministic Temperature: Nilai 0.1 untuk mencegah halusinasi data profil
